# CureLink 14-Day Roadmap

## Phase 1 - 4: Planning, Architecture, Setup, and Authentication
- Database design, UI design.
- Express and React scaffolding.
- Customer, Pharmacy, Admin JWT Auth & RBAC.

## Phase 5: Medicine and Pharmacy Availability
- Medicine master data catalogue.
- Pharmacy geospatial location support.
- Availability status management.

## Phase 6: Multi-Medicine Request Cart
- Add medicines to request cart.
- Multi-medicine broadcasting.

## Phase 7: Prescription Upload and OCR
- Secure Cloudinary upload.
- Tesseract OCR extraction.
- Customer correction & Pharmacist verification.

## Phase 8: Pharmacy Request and Quotation System
- Pharmacy request inbox.
- Private quotation creation.
- Quotation comparison.

## Phase 9: Order Management
- Order lifecycle statuses.
- Historic snapshots of customer/pharmacy data.

## Phase 10: Card Payment and COD
- Payment checkout sessions.
- Secure Webhook handling.

## Phase 11: Notifications and Dashboards
- Real-time Socket.io alerts.
- Dashboards and analytics.

## Phase 12: Testing & Deployment
- E2E tests, documentation, release.
